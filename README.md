# 環球票規劃小幫手

新手友善的亞洲萬里通「寰宇一家多航空公司獎勵機票」（環球票）規劃工具。

- 輸入想去的國家（例如「日本+英國+美國」），自動排出最順路的行程，並給出更省里數的建議
- 一段一段手動排行程，即時計算總飛行距離、級距與里數
- 用白話檢查規則：停留、轉機、開口次數、航空公司家數、是否回到出發國
- 3D 地球／平面地圖顯示路線，按「播放飛行」會有小飛機照順序飛行、在停留點停下來
- 查空位清單：照著到國泰官網逐段查詢並記錄結果
- 我的亞萬點數：記錄每筆累積／兌換，看離目標還差多少、預估達標日期與點數有效期限（資料同步到你自己的 Google 試算表）
- 我的信用卡：記下自己有哪些卡，輸入要刷的通路和金額，比較每張卡能拿到多少亞萬哩程
- 最新活動：整理亞洲萬里通／國泰官網的活動（累積加碼、兌換優惠、合作夥伴等），標出新活動、剩餘天數與跟你的信用卡有關的活動

本工具非國泰航空官方工具，實際規則、里數與空位以國泰航空官網為準。

## 檔案說明

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 網站本體 |
| `data/airports.js` | 機場清單（16 家寰宇一家成員有飛的機場，含中英文名稱） |
| `data/cards.js` | 信用卡預設資料（可累積亞萬的台灣信用卡與各通路元/哩，手動維護） |
| `data/promos.js` | 亞萬官網活動整理（每週由排程整理後更新，也可手動增修） |
| `data/earth-night.jpg` | 3D 地球的夜景城市燈光影像（NASA Earth Observatory「Earth's City Lights」，公有領域，已調亮配合網站配色） |
| `data/routes.js` | 直飛航線表，**每週自動更新，請不要手動修改** |
| `scripts/build_routes.py` | 產生航線表的程式 |
| `.github/workflows/update-routes.yml` | 每週一自動更新航線並重新發布網站 |
| `apps-script/Code.gs` | 亞萬點數紀錄的 Google 試算表後台（貼到 Apps Script 用） |

## 自動更新怎麼運作

每週一早上 8:17（台灣時間），GitHub Actions 會：

1. 下載 [airline-route-data](https://github.com/Jonty/airline-route-data) 最新的全球航線資料
2. 篩出寰宇一家在本站機場之間的直飛航線，產生新的 `data/routes.js`
3. 航線有變動才 commit 回 repo
4. 重新發布 GitHub Pages 網站

想立刻更新：到 repo 的 **Actions** 分頁 → 左邊選「更新航線並發布網站」→ 右邊按 **Run workflow**。

## 亞萬點數紀錄（第一次使用要設定一次）

點數紀錄存在**你自己的** Google 試算表，網站透過 Apps Script 讀寫，手機和電腦看到的是同一份。

1. 到 Google 試算表建立一個新的空白試算表，名稱例如「亞萬點數紀錄」
2. 選單 **擴充功能 → Apps Script**
3. 把編輯器裡原本的內容全部刪掉，貼上 `apps-script/Code.gs` 的全部內容
4. 把第 16 行的 `請改成你自己的密語` 改成一串只有你知道的字（例如 `my-miles-2026x`），按存檔
5. 右上角 **部署 → 新增部署作業** → 齒輪選 **網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按「部署」，第一次會要求授權：選你的帳號 → 進階 → 前往（不安全）→ 允許。這是因為程式是你自己寫的、還沒經過 Google 審核，屬於正常步驟
6. 複製「網頁應用程式」的網址（`https://script.google.com/macros/s/…/exec`）
7. 打開網站 →「我的亞萬點數」分頁 → 貼上網址和第 4 步的密語 → 儲存並連線
8. 第一筆請選「調整」，把官網上看到的目前餘額記下來，之後每次入帳記「累積」、用掉記「兌換」

每台裝置（手機、電腦）第一次打開都要做第 7 步。

**注意**
- **不要把改過密語的 Code.gs 上傳到 GitHub**：repo 是公開的，別人看到密語就能改你的紀錄。repo 裡只放原本的範本就好
- 之後如果修改了 Code.gs，要到 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**，網址才不會變
- 點數有效期限的算法：最後一次「累積」或「兌換」後 18 個月（依國泰官網說明）。「調整」不算活動，不會延長期限
- 預估達標日期是用最近 6 個月的累積速度推算，大額轉點會讓預估暫時變樂觀

## 我的信用卡

- 從預設清單加入你有的卡，或「自訂一張卡」。每個通路填「刷幾元換 1 哩」，空白代表同「國內一般」，0 代表不給哩程
- 在上方輸入通路（例如「日本藥妝」「Agoda」「全聯」），會自動判斷通路類型；判斷不出來時用「國內一般」，可以手動改選
- 已連線試算表時，卡片清單會存到試算表的「設定」工作表，手機和電腦共用；沒連線時只存在這台裝置
- **已經部署過 Apps Script 的話，要更新一次**：把新版 `apps-script/Code.gs` 貼上（記得把密語改回你自己的），再到 部署 → 管理部署作業 → 編輯 → 版本選「新版本」→ 部署。沒更新的話，卡片只會存在這台裝置，頁面上會提示

## 最新活動

- 有你還沒看過的活動時，「最新活動」分頁會出現紅色數字，其他分頁上方也會出現提醒列
- 預設只顯示台灣會員可以參加的活動，取消勾選可以看其他地區限定的活動
- 結束超過的活動會收到「已結束的活動」裡
- **更新方式**：每週三排程會檢查官網並通知你；有新活動時會附上新的 `promos.js`，到 GitHub 的 `data` 資料夾打開 `promos.js` → 鉛筆 → 全選貼上 → Commit。每個活動的 `id` 不要改，網站用它判斷哪些是新活動

## 需要手動維護的部分

- **里數級距表**：國泰調整兌換表時，修改 `index.html` 裡的 `const CHART=`（每列是 `[距離上限, 經濟艙, 商務艙, 頭等艙]`）
- **信用卡預設資料**：銀行改規則時修改 `data/cards.js` 裡那張卡的數字或說明，並把最上面的 `CARD_PRESETS_UPDATED` 改成新的年月。已經加入這張卡的人，下次打開網站會看到「規則有更新」，列出新舊數字，可以一鍵套用（可選擇保留自己改過的通路）或維持原本的數字
- **機場清單**：新航點的中文名稱要手動加進 `data/airports.js`
- **航空公司大本營**：成員航空公司的樞紐機場有變動時，修改 `index.html` 裡的 `const HUBS=`

## 注意事項

- GitHub 規定：repo 超過 60 天沒有任何 commit，排程會被自動暫停。航線有變動時機器人會自動 commit，通常不會發生；如果 Actions 頁面出現暫停提示，按一下重新啟用即可。
- 行程、查空位紀錄存在使用者自己的瀏覽器裡，換網址（例如從 claude.ai 換到 GitHub Pages）後看不到舊紀錄。
- 航線資料可能漏掉季節班或剛開的新航線。
